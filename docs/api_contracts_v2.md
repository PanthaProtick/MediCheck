## 1. Shared standards and invariants

| Item | v2 Specification |
|---|---|
| **Base path & protocol** | Relative `/api/v2`; HTTP JSON over TLS (HTTPS in production; loopback HTTP in local dev). Single origin bundling React frontend and FastAPI backend. |
| **Authentication header** | Protected routes require `Authorization: Bearer <session-token>`. Tokens are verified server-side (Clerk JWT session verifier). Public runtime accepts no shared tokens or bypass headers. |
| **Response headers** | All API responses return `Content-Type: application/json` and `Cache-Control: no-store`. |
| **Hosted deadlines** | Client GET requests: `8000ms`. Client mutations (PUT): `12000ms`. Server DB transaction `statement_timeout`: `5000ms`, `lock_timeout`: `2000ms`, pool acquisition timeout: `2000ms`. Client timeout is not server cancellation. |
| **Enquiry IDs** | Canonical lowercase UUIDv4 string (`^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$`). Generated by browser once per intent. |
| **User IDs** | Canonical lowercase UUIDv4 string. Locally generated and stored in Neon `users` table, mapped 1-to-1 to Clerk opaque `auth_subject`. |
| **Catalog IDs** | Strings matching `^[A-Z][A-Z0-9-]{0,63}$`. Fixture pharmacies: `PHARM-A`, `PHARM-B`. Products: `MED-A`, `MED-B`, `MED-C`. Claims: `CLAIM-A`, `CLAIM-B`. |
| **Units** | `tablet`, `capsule`. Whole canonical units. No fraction, conversion, packaging, or concentration arithmetic. |
| **Quantities** | Strict non-negative JSON integers: requested `1–10,000`, observed `0–10,000`, claim `0–10,000`, discrepancy `-10,000–10,000`. No strings, booleans, floats, or exponents. |
| **Timestamps** | ISO 8601 strings `YYYY-MM-DDTHH:mm:ss[.ffffff](Z|±HH:mm)`. Server output normalized to UTC with `Z`. No epoch integers, date-only strings, or naive datetimes. Microsecond precision preserved. |
| **Pagination** | Paged lists return `{ "items": [...], "limit": int, "offset": int, "has_more": bool }`. Default `limit=20` (max 100), default `offset=0` (max 1000). Server queries `limit + 1` to determine `has_more`. Sorting: caregiver own enquiries sorted `created_at DESC, id DESC`; staff queue sorted `created_at ASC, id ASC` (oldest pending first). Total record counts are never exposed. |
| **Ownership & Privacy** | Caregiver requests are private. Reading an unowned enquiry or creating an enquiry with an existing unowned UUID returns `404 Not Found` (never 403 or 409) to prevent existence probing. |
| **Simulation** | Every evidence, product, and health envelope includes literal JSON `simulated: true`. Synthetic data guarantees no real clinical, pharmacy, or stock reservations. |

## 2. Enum dictionary

| Enum | Values | Semantic meaning |
|---|---|---|
| `Unit` | `tablet`, `capsule` | Product canonical whole-unit dosage form |
| `ReportKind` | `checked`, `unable_to_check` | Physical stock counted vs check cannot be completed |

## 3. Wire schemas and Pydantic models

```python
from datetime import datetime
from enum import Enum
from typing import Annotated, Literal
from uuid import UUID
from pydantic import AwareDatetime, BaseModel, ConfigDict, Field, StringConstraints

Id = Annotated[str, StringConstraints(strict=True, pattern=r"^[A-Z][A-Z0-9-]{0,63}$")]
Text = Annotated[str, StringConstraints(strict=True, min_length=1, max_length=500)]
RequestedQty = Annotated[int, Field(strict=True, ge=1, le=10000)]
ObservedQty = Annotated[int, Field(strict=True, ge=0, le=10000)]
SignedQty = Annotated[int, Field(strict=True, ge=-10000, le=10000)]
PageLimit = Annotated[int, Field(strict=True, ge=1, le=100)]
PageOffset = Annotated[int, Field(strict=True, ge=0, le=1000)]

class Unit(str, Enum):
    tablet = "tablet"
    capsule = "capsule"

class ReportKind(str, Enum):
    checked = "checked"
    unable_to_check = "unable_to_check"

class Status(str, Enum):
    pending = "pending"
    answered = "answered"
    unresolved = "unresolved"

class Conclusion(str, Enum):
    sufficient = "sufficient"
    insufficient = "insufficient"
    unresolved = "unresolved"

class Reason(str, Enum):
    awaiting_check = "awaiting_check"
    checked_meets_request = "checked_meets_request"
    checked_below_request = "checked_below_request"
    cannot_check = "cannot_check"
    observation_time_unknown = "observation_time_unknown"
    evidence_conflict = "evidence_conflict"

# Core Models
class Pharmacy(BaseModel):
    model_config = ConfigDict(extra="forbid")
    id: Id
    name: Text
    active: bool
    simulated: Literal[True]

class PharmacyMembership(BaseModel):
    model_config = ConfigDict(extra="forbid")
    pharmacy_id: Id
    role: Literal["staff"]
    active: bool
    created_at: AwareDatetime

class MeResponse(BaseModel):
    model_config = ConfigDict(extra="forbid")
    user_id: UUID
    auth_subject: Text
    active: bool
    memberships: list[PharmacyMembership]

class Product(BaseModel):
    model_config = ConfigDict(extra="forbid")
    id: Id
    name: Text
    strength: Text
    form: Text
    unit: Unit

class Claim(BaseModel):
    model_config = ConfigDict(extra="forbid")
    id: Id
    pharmacy_id: Id
    product_id: Id
    quantity: ObservedQty | None
    unit: Unit
    recorded_at: AwareDatetime | None
    loaded_at: AwareDatetime
    source: Text
    simulated: Literal[True]

class BootstrapResponseV2(BaseModel):
    model_config = ConfigDict(extra="forbid")
    pharmacies: list[Pharmacy]
    products: list[Product]
    claims: list[Claim]
    simulated: Literal[True]

# Request Bodies
class CreateEnquiryRequest(BaseModel):
    model_config = ConfigDict(extra="forbid")
    pharmacy_id: Id
    product_id: Id
    requested_quantity: RequestedQty
    unit: Unit

class ObservationRequest(BaseModel):
    model_config = ConfigDict(extra="forbid")
    product_id: Id
    unit: Unit
    kind: ReportKind
    obtainable_quantity: ObservedQty | None
    observed_at: AwareDatetime | None
    unresolved_reason: Literal["cannot_check"] | None

# Saved & View Models
class ObservationV2(ObservationRequest):
    reported_by_user_id: UUID
    submitted_at: AwareDatetime
    basis: Literal["staff_reported_obtainable_count", "unable_to_check"]
    simulated: Literal[True]

class Answer(BaseModel):
    model_config = ConfigDict(extra="forbid")
    conclusion: Conclusion
    reason: Reason
    discrepancy_units: SignedQty | None
    message: Text
    limitations: list[Text]

class EnquiryRecordV2(BaseModel):
    model_config = ConfigDict(extra="forbid")
    id: UUID
    owner_user_id: UUID
    pharmacy_id: Id
    product: Product
    requested_quantity: RequestedQty
    unit: Unit
    created_at: AwareDatetime
    claim: Claim | None
    simulated: Literal[True]

class EnquiryViewV2(EnquiryRecordV2):
    served_at: AwareDatetime
    observation: ObservationV2 | None
    status: Status
    answer: Answer

class EnquiryPage(BaseModel):
    model_config = ConfigDict(extra="forbid")
    items: list[EnquiryViewV2]
    limit: PageLimit
    offset: PageOffset
    has_more: bool

# Health & Error Models
class HealthResponseV2(BaseModel):
    model_config = ConfigDict(extra="forbid")
    status: Literal["ready"]
    storage: Literal["postgresql"]

class ErrorDetail(BaseModel):
    model_config = ConfigDict(extra="forbid")
    code: Literal[
        "validation_error", "unauthorized", "forbidden", "not_found",
        "immutable_conflict", "storage_unavailable", "internal_error",
        "method_not_allowed", "unsupported_media_type", "auth_unavailable",
        "rate_limited"
    ]
    message: Text
    fields: list[Text]

class ErrorResponse(BaseModel):
    model_config = ConfigDict(extra="forbid")
    error: ErrorDetail
```

## 4. Endpoints and HTTP boundaries

### B01 — Health check
- **Route**: `GET /api/v2/health`
- **Auth**: Public (no token required).
- **Deadline**: 8000ms.
- **Success**: `200 OK` -> `HealthResponseV2` (`{"status":"ready","storage":"postgresql"}`).
- **Failure**: `503 Service Unavailable` (`code: storage_unavailable`) if PostgreSQL connectivity or schema migration ledger check fails.

### B02 — Authenticated principal (`/me`)
- **Route**: `GET /api/v2/me`
- **Auth**: Verified session required (`Authorization: Bearer <token>`).
- **Deadline**: 8000ms.
- **Success**: `200 OK` -> `MeResponse`. Returns stable local `user_id`, `auth_subject`, `active: true`, and list of active `memberships`.
- **Failure**: `401 Unauthorized` if token missing, expired, or invalid. `403 Forbidden` if local user account is disabled. `503 Service Unavailable` (`code: auth_unavailable`) if auth provider verification is unreachable.

### B03 — Multi-pharmacy bootstrap
- **Route**: `GET /api/v2/bootstrap`
- **Auth**: Verified session required.
- **Deadline**: 8000ms.
- **Success**: `200 OK` -> `BootstrapResponseV2`. Returns active `pharmacies` (PHARM-A and PHARM-B), all catalog `products`, and per-pharmacy initial `claims`. Does not expose any enquiry records.
- **Failure**: `401 Unauthorized` / `403 Forbidden` / `503 Service Unavailable`.

### B04 — List own enquiries
- **Route**: `GET /api/v2/enquiries?limit=20&offset=0`
- **Auth**: Verified session required.
- **Query Params**: `limit` (default 20, max 100), `offset` (default 0, max 1000).
- **Deadline**: 8000ms.
- **Success**: `200 OK` -> `EnquiryPage`. Strictly filtered to enquiries where `owner_user_id == principal.user_id`. Ordered `created_at DESC, id DESC`.
- **Failure**: `401 Unauthorized` / `403 Forbidden` / `422 Validation Error` (offset/limit out of bounds).

### B05 — Create or replay own enquiry
- **Route**: `PUT /api/v2/enquiries/{id}`
- **Auth**: Verified session required.
- **Body**: `CreateEnquiryRequest`.
- **Deadline**: 12000ms.
- **Behavior**:
  - `owner_user_id` is assigned server-side from the verified principal.
  - If `{id}` does not exist: inserts enquiry and snapshots catalog product and pharmacy claim. Returns `201 Created` -> `EnquiryViewV2`.
  - If `{id}` exists with identical `owner_user_id`, `pharmacy_id`, `product_id`, `requested_quantity`, `unit`: returns `200 OK` -> `EnquiryViewV2` (safe idempotent replay).
  - If `{id}` exists with identical `owner_user_id` but altered request parameters: returns `409 Conflict` (`code: immutable_conflict`).
  - If `{id}` exists with a **different `owner_user_id`**: returns `404 Not Found` (`code: not_found`, `fields: ["id"]`) to prevent existence probing.
- **Failure**: `401 Unauthorized` / `403 Forbidden` / `404 Not Found` / `409 Conflict` / `422 Validation Error` / `503 Storage Unavailable`.

### B06 — Read single enquiry
- **Route**: `GET /api/v2/enquiries/{id}`
- **Auth**: Verified session required.
- **Deadline**: 8000ms.
- **Authorization**:
  - Caller is the enquiry owner (`principal.user_id == enquiry.owner_user_id`): Allowed.
  - Caller has active staff membership at `enquiry.pharmacy_id`: Allowed.
  - Otherwise: Returns `404 Not Found` (`code: not_found`). Never reveals whether an unowned enquiry exists at another pharmacy.
- **Success**: `200 OK` -> `EnquiryViewV2`.
- **Failure**: `401 Unauthorized` / `403 Forbidden` / `404 Not Found`.

### B07 — Staff pending queue
- **Route**: `GET /api/v2/staff/enquiries?pharmacy_id=PHARM-A&limit=20&offset=0`
- **Auth**: Verified session required.
- **Query Params**: `pharmacy_id` (required `Id`), `limit` (default 20, max 100), `offset` (default 0, max 1000).
- **Deadline**: 8000ms.
- **Authorization**: Caller MUST have an active staff membership for the requested `pharmacy_id`. If caller does not hold membership: returns `403 Forbidden` (`code: forbidden`).
- **Success**: `200 OK` -> `EnquiryPage` (pending items only, ordered `created_at ASC, id ASC`).
- **Failure**: `401 Unauthorized` / `403 Forbidden` / `422 Validation Error`.

### B08 — Submit or replay observation
- **Route**: `PUT /api/v2/enquiries/{id}/observation`
- **Auth**: Verified session required.
- **Body**: `ObservationRequest`.
- **Deadline**: 12000ms.
- **Authorization & Invariants**:
  - Caller MUST have an active staff membership for `enquiry.pharmacy_id`. If not: `403 Forbidden`.
  - Server assigns `reported_by_user_id = principal.user_id` and `submitted_at = utc_now()`.
  - If no observation exists: validates exact product/unit match, non-future observation time, coherence. Inserts row. Returns `201 Created` -> `EnquiryViewV2`.
  - If an observation already exists:
    - If `existing.reported_by_user_id == principal.user_id` AND identical normalized payload: returns `200 OK` -> `EnquiryViewV2` (safe idempotent replay).
    - If `existing.reported_by_user_id != principal.user_id` (even if report body is identical): returns `409 Conflict` (`code: immutable_conflict`). Original reporter and timestamp are preserved.
    - If `existing.reported_by_user_id == principal.user_id` but payload differs: returns `409 Conflict` (`code: immutable_conflict`).
- **Failure**: `401 Unauthorized` / `403 Forbidden` / `404 Not Found` / `409 Conflict` / `422 Validation Error`.
